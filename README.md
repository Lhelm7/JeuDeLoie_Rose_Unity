# JeuDeLoie_Rose_Unity

Seul dans le noir 

Pitch : Personnage enfermé dans un vaisseau, mais il n’est pas tout seul... 

Il va devoir parvenir à rallumer les lumières du vaisseau avant de se retrouver face à face à une créature monstrueuse. 

Ainsi pour parvenir à rallumer les lumières il devra trouver des ressources pour survivre qui vont concrètement l’aider à avancer. (Ex ; case dé pipé) 

But : Rallumer les lumières avant de se faire attraper par le monstre, à chaque tour évènements “aléatoire” intensité des events augmente au fil des tours, le monstre va impacter l’avancer du joueur etc... (Ex : changer l’ordre de certaines cases, faires disparaitre des cases, mettre des cases malus, éteindre une lumière qui avait été allumé...etc.) 

Le monstre peut être physique ou dans l’ombre (pas forcément visible dans le monde) 

Des cases pourront être en lien avec des effets du monstres afin de les contrer/annuler. 

Les lumières seront des cases spécifiques sur le plateau, mais les cases lumières auront différentes manières d’être rallumé ;  

    Le joueur devra soit avoir une ressource (ex ; ampoule) s'il ne l’a pas quand il passe sur la case devra recommencer.  

    Soit un mini jeu, avec par exemple regrouper des fils au bon endroit (mini puzzle). 

Conditions de victoire : Le joueur gagne ainsi le jeu une fois qu’il a rallumé toutes les lumières (pas de nombre défini ~3) du plateau. 

Idée de fin : Une fois toutes les lampes rallumer le joueur se fera courser par le monstre, il devra parvenir à revenir à la case départ, avant de se faire rattraper par le monstre, si échoue ne perd pas mais aura une confrontation avec le monstre (duel)
